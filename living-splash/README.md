# Kalium living splash

Client preview of the Figma splash page with the saved interactive Emergence animation.

The illustration stays fixed; its selected tendrils respond to the pointer. Fonts and all animation assets are hosted here. The contact link is a placeholder. The homepage links to the Dynamic Equity paper.

This GitHub Pages edition uses a committed motion setup. The bone editor and shared saving remain on the private Kalium Site. To update this preview, export the latest setup from the editor, replace client-preview/motion-setup.json in the Kalium project, and run npm run build:pages. Copy the pages output into this folder and commit it.
